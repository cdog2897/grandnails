# Grand Nails & Spa

A responsive, one-page React and Vite website for Grand Nails & Spa in Laramie, Wyoming.

## Run locally

```sh
npm install
npm run dev
```

Use `npm run build` to produce the production files in `dist/` and `npm run lint` to check the source.

Business details, reviews, photography, and the hours discrepancy are documented in [SOURCES.md](./SOURCES.md). The photographs are licensed editorial images.
